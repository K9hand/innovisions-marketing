HR & Payroll

Step-by-step guide to managing HR and payroll in InnoVisions ERP: employee management, payroll runs, PAYE/UIF calculations, leave tracking, ESS portal, and IRP5 certificates.

Module: HR & Payroll Difficulty: Advanced Prerequisites: Company tax settings configured with SARS rates, employee records created

The HR & Payroll module manages the full employee lifecycle — from hire to termination. It handles complex payroll calculations (overtime, shift differentials, commissions), SARS-compliant PAYE/UIF/SDL deductions, leave accrual and tracking, employee self-service, and year-end IRP5 generation. Every payroll run posts to the GL with cost centre allocation for accurate departmental P&L reporting.

Warning

Payroll runs should always be previewed and verified before posting. Run the pre-payroll validation report to check for missing data — unverified timesheets, unallocated earnings, and GL mapping errors.

Configure Advanced Payroll Settings

1
Set up earnings and deduction codes

Navigate to Payroll → Settings → Earnings/Deductions. Define all earning types (basic salary, overtime, commission, bonus, allowance) and deduction types (PAYE, UIF, pension fund, medical aid, garnishee, union dues). Each code maps to a GL account and has a tax treatment classification.

2
Configure pay groups

Create pay groups for different employee categories — monthly salaried, weekly wage, expatriate, contractors. Each group has a payroll frequency, default earnings, and processing calendar. Pay groups can be processed independently on different schedules.

3
Set SARS tax table version

Tax tables are updated annually by SARS. Configure the current tax year's tables including tax brackets, rebates (primary, secondary, tertiary), and tax thresholds. The system auto-calculates PAYE using the active table version. Set a reminder for annual table updates.

Process Payroll with Complex Earnings

1
Configure overtime rules

Navigate to Payroll → Settings → Overtime Rules. Define overtime multipliers: 1.5x for normal overtime, 2x for Sundays, 2.5x for public holidays. Set daily and weekly overtime thresholds. Overtime can be calculated automatically from approved timesheets or entered manually.

2
Create a payroll run

Navigate to Payroll → Payroll Runs → New. Select the pay group, period, and month. The system loads all active employees. Verify timesheet data, ad-hoc adjustments, overtime, commissions, and deductions. Run the pre-payroll validation to flag issues before processing.

3
Handle retroactive adjustments

For late timesheets or salary corrections, use retroactive adjustment entries. The system recalculates PAYE for the adjusted period and shows the net adjustment on the current payslip. Retroactive entries are flagged in the audit trail and on the payslip for employee transparency.

4
Preview and post

Generate payslip previews for all employees. Verify gross-to-net calculations. Run the payroll validation report checking: GL account mapping completeness, zero net pay exceptions, high-value adjustment flags. Post to finalise — this makes payslips available on ESS and creates the GL journal.

Tip

Set up pay groups to run payroll for different employee categories separately — monthly salaried vs weekly wage staff can have different processing schedules.

Manage PAYE, UIF, and SDL

1
Review SARS calculations

After each payroll run, navigate to Payroll → SARS Returns. The system calculates PAYE using current tax tables with correct rebates. Verify UIF at 1% employee + 1% employer (capped at the annual threshold). SDL is calculated at 1% if the employer's annual payroll exceeds the R500,000 threshold.

2
Generate and reconcile EMP201

The EMP201 return aggregates PAYE, UIF, and SDL for the month. Run the EMP201 reconciliation report comparing the return totals against GL liability accounts. Any discrepancy must be investigated before submission. Schedule EMP201 generation as part of the month-end checklist.

3
Submit to SARS eFiling

Export the EMP201 file in SARS XML format. Upload via eFiling and record the submission reference number in the system. Track payment due dates — EMP201 is due by the 7th of the following month. Late submissions incur penalties of 10% of the amount due plus interest.

Handle Third-Party Payments

1
Configure deduction codes

Set up third-party deduction codes for garnishee orders, union membership fees, pension fund contributions, and medical aid. Each code requires a third-party reference (garnishee order number, union code, fund membership number).

2
Process deductions in payroll

Deductions are automatically calculated during payroll based on employee deduction profiles. Garnishee deductions follow the prescribed percentage or fixed amount per the court order. Pension fund deductions can be fixed amount, fixed percentage, or percentage of pensionable earnings.

3
Generate payment batches

After payroll posting, generate third-party payment batches per deduction type. The system aggregates all employee deductions for each third party and creates a payment file. Include remittance advice with employee-level breakdown. Schedule payments in line with each third party's terms.

Configure GL Integration for Payroll

1
Map earnings and deductions to GL accounts

Navigate to Payroll → Settings → GL Mapping. Map each earning code to the appropriate expense GL account (e.g., Salaries — 6100, Overtime — 6110, Employer Pension — 6150). Map deduction codes to liability accounts (e.g., PAYE Liability — 2200, Pension Fund Payable — 2250).

2
Configure cost centre allocation

Set up payroll cost allocation rules by department or employee. For example, production department salaries allocate to 80% Cost Centre A (Manufacturing) and 20% Cost Centre B (Maintenance). The allocation split is applied automatically during payroll GL posting.

3
Run month-end payroll accrual

If payroll crosses month-end, run the payroll accrual journal to match costs to the correct period. The accrual estimates salary costs based on the prior run and reverses when the actual payroll posts. This ensures accurate monthly P&L even with payroll timing differences.

Manage Employee Lifecycle Automations

1
Configure onboarding workflow

Navigate to HR → Settings → Onboarding. Create a checklist of tasks triggered on employee creation: IT system access provisioning, benefits enrolment, document collection (contract, ID, tax certificate), mandatory training assignment. HR admins track completion status per new hire.

2
Set up offboarding process

Configure the termination workflow triggered when an employee's status changes to terminated. Tasks include: final payslip calculation (leave payout, severance pay), asset return tracking, IT access revocation, exit interview scheduling, certificate of service generation.

3
Manage transfers and promotions

Employee transfer/promotion events update: department assignment, cost centre allocation, salary and grade, manager reporting line. The system retains the employee's history and job change audit trail. Transfer effective date controls payroll allocation for partial periods.

Configure Leave Management

1
Set up leave types and policies

Navigate to HR → Leave → Settings. Define annual leave (minimum 15 days per year per BCEA), sick leave (30 days per 36-month cycle), family responsibility leave (3 days per year), and study leave. Set accrual method: once-off annual allocation or monthly pro-rata accrual.

2
Configure leave approval workflow

Set up leave request routing: employee submits → manager approves → HR notified. Configure automatic delegation when managers are on leave. Set escalation if not approved within 48 hours. Leave requests that would exceed available balance require director-level approval.

3
Track leave liability

Run the leave liability report to calculate the accrued leave cost at month-end. The report shows each employee's leave balance at their current hourly rate. The liability value posts to a leave accrual GL account and reverses as leave is taken.

Run Payroll Analytics and Reporting

1
Configure payroll dashboards

Navigate to Reports → Payroll Dashboards. Configure widgets: headcount by department, payroll cost trend (monthly/quarterly), overtime as % of total payroll, leave utilisation by type, PAYE/UIF/SDL summary. Dashboards refresh after each payroll run.

2
Run employee cost analysis

Generate the employee cost analysis report showing total cost per employee (salary, bonuses, employer taxes, benefits). Compare against budget or prior periods. Calculate cost-to-company and total employment cost per FTE. Export for annual budgeting and headcount planning.

3
Run year-end procedures

Navigate to Payroll → Tax Year-End. Verify year-to-date payroll data. Run IRP5 generation — the system creates certificates for all employees with earnings in the tax year. Distribute IRP5s via ESS and submit EMP501 reconciliation to SARS by the deadline (31 May for manual, 31 July for electronic).

Info

Retroactive adjustments create additional payslip lines with the correct tax calculation for the adjusted period. The system recalculates PAYE automatically using the SARS tax table in effect for the adjusted period.

Module: Production & Manufacturing Difficulty: Advanced Prerequisites: Stock module with items created, BOM components defined, work centres configured

The Production & Manufacturing module manages your end-to-end manufacturing execution — from demand forecasting and BOM engineering through MRP, production execution, quality control, cost analysis, and continuous improvement. Multi-level BOMs support complex assemblies, routing engines track operation-level costs, and MRP reconciles demand signals with supply chain constraints.

Info

MRP is typically run overnight. Schedule it after all POs, sales orders, and work orders are updated for the day.

Design Multi-Level Bills of Materials

1
Create the BOM header

Navigate to Production → BOMs and click New BOM. Select the finished product and choose between an Engineering BOM (designed specification) or Manufacturing BOM (production execution view). Set the BOM type to Standard, Phantom (for sub-assemblies consumed directly into parent), or Planning (for forecasting only).

2
Add components with quantity and scrap

Add each raw material or sub-assembly, specifying the quantity per finished unit. Configure the scrap percentage to account for manufacturing losses — for example, 5% scrap on steel sheet accounts for edge trim waste. Set component yield if using variable-ratio BOMs for process manufacturing.

3
Configure co-products and by-products

Add co-products (multiple primary outputs from one process) with individual quantities and cost allocation percentages. Define by-products with negative quantities or disposal cost to automatically reduce WIP value at production posting.

4
Set BOM version control

Enable versioning to track engineering changes over time. Set effective from/to dates per version. Only the active version is used for MRP and work order creation. Approve through ECO workflow before a new version replaces the current standard.

5
Validate and cost-roll-up

Run BOM validation to check for missing components, inactive items, or circular references. Run cost roll-up to calculate the standard cost from component costs and routing operations. Review the manufacturing cost breakdown before releasing for production.

Configure Production Routing and Work Centres

1
Define work centres

Navigate to Production → Routing → Work Centres. Create each machine, workstation, or production line. Configure rated capacity in hours per day, efficiency percentage (actual output vs rated), and utilisation percentage. Set cost rates for labour, machine, and overhead per hour.

2
Create operation sequence

For each product routing, define the sequence of operations. Each operation references a work centre. Set setup time (fixed per batch) and run time (per unit). Add queue time, move time, and wait time for realistic throughput scheduling.

3
Configure parallel and overlapping operations

Set operation overlap percentage to allow the next operation to start before the previous one finishes (e.g., 50% overlap for assembly lines). Configure parallel operations for tasks that can run simultaneously at different work centres.

4
Assign routing to BOM versions

Link each BOM version to the appropriate routing version. When a work order is created, the system loads the routing automatically. The routing drives the production schedule, capacity requirements, and operation-level cost collection.

Run Material Requirements Planning (MRP)

1
Set MRP parameters

Navigate to Production → MRP → Parameters. Configure the planning horizon (typically 12 weeks), order modifiers (minimum/multiple order quantities per item), lead time buffers, and safety stock policy. Choose regeneration (full net-change) or net-change (incremental) planning mode.

2
Run net requirements calculation

Click Run MRP. The system calculates gross demand from sales orders, MPS, and forecasts. It nets against current stock, open POs, work-in-progress, and scheduled receipts. The output is a set of planned orders with quantities and suggested dates.

3
Review pegging and action messages

Review the pegging report to trace each planned order back to its demand source (sales order, MPS, forecast). Action messages highlight exceptions: Release (planned orders due), Reschedule In/Out (date misalignment), Cancel (surplus supply).

4
Convert planned orders

Select planned orders and click Convert to generate firm work orders and purchase orders. The system creates POs for purchased items with the correct supplier and delivery dates, and work orders for manufactured items with BOM and routing. Review ATP before converting.

Tip

Run MRP in simulation mode first to review the impact of demand changes before committing to new POs and work orders.

Create and Release Work Orders

1
Create work order

Work orders can be created manually, from MRP conversion, directly from a sales order, or from the MPS. Navigate to Production → Work Orders → New. Select the product, BOM version, routing, and quantity. The system pre-calculates material requirements and operation durations.

2
Check material availability

Run material availability check to identify shortages. The system compares required BOM quantities against on-hand + on-order stock. Shortages are flagged. Partial release can proceed with available stock while back-ordered components are tracked.

3
Schedule and release

Set planned start/end dates. The system performs backward scheduling from due date or forward scheduling from start date based on routing operation times. Release the work order to reserve stock and make it available on the shop floor. Released orders appear on the dispatch board.

4
Handle work order lifecycle

Work orders progress through Draft → Released → In Progress → Completed → Closed. Use Hold status to pause production for quality issues or material shortages. Click-by-click operation status tracking can be enabled for detailed WIP visibility at each routing step.

Record Production with Variance Analysis

1
Record production output

Navigate to the work order and click Record Production. Enter the finished good quantity produced. Record by-products and scrap. The system can backflush component consumption based on BOM quantities, or you can issue materials manually for more precise tracking.

2
Post and review GL impact

Post the production completion. The system creates a manufacturing journal entry: credits WIP (raw material consumption + labour + overhead applied), debits finished goods inventory (standard cost of output), and posts variances to configured variance accounts.

3
Analyse variances

Run the work order variance report: material usage variance (actual component qty vs BOM qty), labour efficiency variance (actual hours vs routing hours), rate variance (actual labour rate vs standard), and overhead absorption variance. Investigate variances exceeding configured thresholds.

Warning

Engineering changes that affect active work orders require careful disposition planning. Use the change impact report before approving to identify affected orders and their current production stage.

Manage Engineering Changes

1
Create ECO workflow

Navigate to Production → Engineering → Change Orders. Create an Engineering Change Order (ECO) describing the proposed change, reason, and affected BOMs/routings. Route through approval stages: Engineering Manager → Production Manager → Quality.

2
Run impact analysis

Before approving, run the change impact report showing: affected BOM versions, active work orders using the current BOM, existing stock of the old component (use-as-is vs scrap vs rework), customer orders specifying the current version. Cost impact analysis compares old vs new BOM cost.

3
Implement and phase in

Approve the ECO to create a new BOM version with effective date. Use phase-in/phase-out dates to transition smoothly. For example, effective from 1 March — work orders released before use old BOM, after use new BOM. Existing WIP is completed with the old BOM unless disposition requires rework.

Implement Quality Control in Production

1
Create inspection plans

Navigate to Production → Quality → Inspection Plans. Define inspection criteria per product or operation: measurements to check, acceptable ranges (upper/lower spec limits), sampling frequency (every nth unit or batch), and AQL (acceptable quality level) for statistical sampling.

2
Link to BOM or routing operation

Assign inspection plans to a product, BOM version, or specific routing operation. For example, dimensional check after Operation 20 (machining) and before Operation 30 (assembly). The inspection is triggered automatically when production is recorded at that operation.

3
Record non-conformance

When inspection fails, create a Non-Conformance Report (NCR). Classify severity (minor/major/critical). Route for disposition: Use-as-Is, Rework, Scrap, or Return to Supplier. Corrective action tracking ensures root cause analysis and prevents recurrence.

4
Track quality KPIs

Monitor production quality metrics: first-pass yield (FPY), scrap rate percentage, rework cost as % of production cost, supplier defect ppm. Configure threshold alerts — e.g., if scrap rate exceeds 3% in a shift, notify the production manager automatically.

Configure Production Costing

1
Set costing method

Choose between Standard Cost (pre-set costs with variance tracking) or Actual Cost (costs calculated from actual transactions). Standard cost requires periodic cost roll-ups and variance analysis. Actual cost provides real-time profitability but requires more processing.

2
Run cost roll-up

Navigate to Production → Costing → Cost Roll-Up. Select the BOM and routing. The system calculates: material cost (component qty × standard cost), labour cost (operation hours × work centre rate), overhead cost (operation hours × overhead rate). Review rolled-up cost before updating standard costs.

3
Configure variance accounts

Set GL accounts for each variance type: Material Usage, Material Price, Labour Rate, Labour Efficiency, Overhead Absorption, and Production Volume. Variances post automatically at production completion. Review the monthly manufacturing P&L to identify cost trends and improvement areas.

Optimise Production Scheduling

1
Choose scheduling method

Use Forward Scheduling (start as soon as materials available — pushes completion date out) or Backward Scheduling (start as late as possible to meet due date). Finite scheduling respects work centre capacity and shows overload/underload by period.

2
Use the Gantt chart board

The production schedule board (Gantt chart) shows work orders by work centre across time. Drag-drop for manual rescheduling. Colour-coded by status (released, in progress, completed, late). Identify capacity bottlenecks where work centre utilisation exceeds 90%.

3
Monitor OEE dashboards

Configure OEE (Overall Equipment Effectiveness) calculation for each work centre: Availability (actual run time / planned time), Performance (actual output / max output), Quality (good units / total units). Target OEE of 85%+ for world-class manufacturing.

Info

Set up work centre efficiency rates (e.g., 85%) to account for breaks and downtime. This gives realistic capacity planning rather than theoretical maximum.

Related Modules

Stock & Inventory

Backflushing automates component consumption when production output is recorded. Configure backflush at operation completion for WIP tracking. BOM component reservations ensure material availability at work order release.

Procurement & Supply Chain

MRP-generated POs flow directly to procurement with the correct supplier, quantity, and required-by date based on routing lead times and component lead times.

Projects & Job Costing

Work order costs (materials, labour, overhead) can be tracked at the project level when a work order is linked to a job. Production variance analysis feeds into job profitability reporting.

Financial Management

Manufacturing variances post to GL variance accounts for material usage, labour rate, and overhead absorption. WIP valuation is maintained at standard or actual cost through production posting.

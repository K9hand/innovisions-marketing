Financial Management

Step-by-step guide to managing your company's finances in InnoVisions ERP: general ledger, accounts payable and receivable, cash flow, budgeting, and bank reconciliation.

Module: Financial Management Difficulty: Advanced Prerequisites: Chart of accounts configured, at least one period open

The Financial Management module serves as the central hub for all financial operations in InnoVisions ERP, supporting multi-currency transaction processing, inter-company eliminations, and automated allocations across cost centres and dimensions. The period-end close workflow orchestrates depreciation runs, inventory revaluations, accrual postings, and inter-company reconciliations into a single controlled process. Real-time consolidation across legal entities is supported through configurable elimination rules and currency translation adjustments, while the audit trail captures field-level before/after values with full user attribution for every GL transaction.

Configure Advanced Chart of Accounts

1
Define account groups with roll-up rules

Create account groups (assets, liabilities, equity, income, expenses) and configure roll-up hierarchies that drive financial statement line items. Each group can have alternate hierarchies for management reporting vs statutory reporting. Set consolidation rules per group to define how balances from subsidiary entities are aggregated.

2
Integrate cost centres and dimensions

Configure mandatory or optional dimensions per account group — cost centre, department, project, region — and set default dimension derivation rules based on transaction source (e.g., sales orders default to the customer's region dimension). Dimension combinations can be restricted to prevent invalid posting pairs.

3
Set up alternate hierarchies for reporting

Create multiple reporting hierarchies on the same base accounts, such as a management view that groups by responsibility centre and a statutory view that follows IFRS or GAAP classification. Assign hierarchy-specific sort orders and subtotal definitions for the report designer.

4
Configure inter-company account mapping

Designate inter-company clearing accounts and map them per subsidiary pair. When an inter-company transaction is posted, the system automatically creates matching entries in both entities' GLs with offsetting balances. Validation rules ensure the due-to/due-from accounts remain in balance after elimination.

5
Set up auto-account derivation rules

Define rules that automatically derive the GL account based on transaction type, item group, supplier/customer category, and warehouse. For example, stock receipts from local suppliers route to Inventory - Raw Materials account, while imports route to Inventory - In Transit. Rules are evaluated in priority order with fallback accounts for unmatched transactions.

Info

Always run the trial balance before closing a period to verify debits equal credits across all accounts.

Process Multi-Currency Transactions

1
Set up currencies and exchange rates

Maintain a currency master table with ISO codes, symbols, and decimal precision. Configure exchange rate types — spot rate, month-end rate, average rate — and set up automatic rate feeds from central banks or manual rate entry with effective dates. Each rate type can be assigned to different transaction contexts (spot for invoicing, average for reporting).

2
Process transactions in foreign currency

When entering AP bills, AR invoices, or journal entries in a foreign currency, the system records both the transaction currency amount and the equivalent base currency amount using the spot rate on the document date. The exchange rate can be overridden with approval. The system stores the original currency amount for revaluation purposes.

3
Calculate realized vs unrealized FX gains/losses

Realized FX gains/losses are calculated at the point of settlement — when an invoice is paid, the system compares the settlement rate to the original invoice rate and posts the difference to the designated FX gain/loss account. Unrealized gains/losses arise from period-end revaluation of open foreign currency balances and are reversed in the following period.

4
Run period-end revaluation

Using the month-end exchange rate type, revalue all open foreign currency balances — bank accounts, AP/AR sub-ledgers, inter-company loans. The revaluation report shows the pre- and post-revaluation amounts per account. Review and approve the revaluation journal before posting. Unrealized gains/losses post to separate GL accounts and auto-reverse on the first day of the next period.

5
Reconcile multi-currency bank accounts

Upload bank statements in the account's native currency. The system matches transactions using the original currency amounts and handles currency conversion for base currency GL posting. Any rounding differences between the bank exchange rate and the system rate post to a currency rounding account.

Warning

Foreign currency revaluation creates unrealized FX gains/losses that must be reversed in the next period. Review the revaluation report before posting.

Manage Inter-Company Transactions

1
Configure inter-company account mapping

For each pair of related entities, map the inter-company receivable and payable accounts. Define which transaction types flow through inter-company accounts — inter-company sales, cost recharges, management fees, loans. Set up default inter-company terms and currency preferences per relationship.

2
Define elimination rules and auto-reversal

Configure elimination rules that specify which inter-company balances to eliminate during consolidation. Rules can be percentage-based (eliminate 100% of inter-company revenue and expense) or fixed-amount. Auto-reversal templates ensure that inter-company entries recorded in one entity automatically generate the mirror entry in the counterparty entity.

3
Run inter-company reconciliation

Execute the inter-company reconciliation report to compare due-to and due-from balances between entities. The report highlights unmatched transactions, currency translation differences, and timing discrepancies. Investigate and resolve variances before period close — unresolved differences prevent consolidation finalization.

4
Generate consolidated financial reports

Using the consolidation engine, combine subsidiary financial data into group-level reports. The system applies elimination journals, performs currency translation using period-end and average rates, and calculates non-controlling interest. Consolidated reports can be generated for management review or statutory filing with differing hierarchy views.

5
Apply transfer pricing considerations

For inter-company goods and services, configure transfer pricing rules based on cost-plus, market rate, or negotiated price methods. The system validates inter-company invoice prices against the defined method and flags deviations for review. Maintain transfer pricing documentation and audit trails for tax compliance purposes.

Set Up Automated Allocations

1
Define allocation rules by method

Create allocation rules using percentage-based (allocate 60% to department A, 40% to department B), activity-based (allocate by headcount, square footage, machine hours), or driver-based methods. Each rule specifies the source account, the target accounts with dimensions, and the allocation basis with source data from a lookup table or formula.

2
Configure recurring allocation schedules

Set up monthly, quarterly, or annual schedules that trigger allocation execution automatically. Schedules can be date-driven or event-driven (e.g., triggered by period close initiation). Multiple allocations can be chained in a sequence where the output of one allocation becomes the input pool for the next.

3
Manage overhead cost pools

Define cost pools that collect shared expenses (rent, utilities, IT, admin salaries) before allocation. Pool accounts are cleared to zero after allocation posting. Set up tiered allocation — allocate IT costs to departments, then allocate a portion of each department's total to projects based on project hours.

4
Review allocation audit trail

Each allocation run generates a detailed audit report showing the source amount, allocation basis values, target distribution, and any rounding residuals. The audit trail supports drill-down from the allocated journal entry back to the source transactions. Re-run allocations as needed before period finalization — previous allocations are automatically reversed.

Tip

Use allocation rules for shared costs like rent and utilities. Automate monthly overhead absorption instead of manual journal entries.

Run Period-End Close

1
Execute the close checklist and task management

Access the period-end close checklist from the GL module. The checklist drives a sequential workflow — verify bank reconciliations, approve all pending journals, run depreciation, post accruals, revalue FX, reconcile inter-company accounts — with each task requiring sign-off before the next begins. Task assignments and deadlines are tracked with escalation reminders.

2
Post accrual and prepayment journals

Create accrual journals for expenses incurred but not yet invoiced, and prepayment amortization schedules for expenses paid in advance. Recurring journal templates can automate month-end accruals with auto-reversal in the following period. Prepayment schedules automatically post monthly amortization entries based on the amortization pattern (straight-line, usage-based).

3
Run depreciation and inventory revaluation

Execute the fixed asset depreciation run for the period — the system calculates depreciation for all active assets using the assigned method (straight-line, reducing balance, sum-of-digits) and posts to the accumulated depreciation and depreciation expense accounts. Simultaneously, run inventory revaluation to adjust stock values for period cost changes.

4
Complete inter-company reconciliation

Run the inter-company reconciliation report to confirm all due-to/due-from balances match between entities. Post any required adjusting entries to clear residual differences. The reconciliation must be approved by both entities' finance managers before consolidation can proceed.

5
Lock the period and open the next period

Once all close tasks are signed off, generate the final trial balance and financial statements for review. Lock the completed period to prevent further posting. Open the next accounting period with opening balances carried forward. Configure period access permissions to control who can unlock a closed period for adjustments.

Configure Approval Workflows

1
Set up purchase order approval routing

Define approval tiers based on PO value thresholds — department manager approves up to R50,000, director up to R250,000, CFO over R250,000. Configure multi-level approval for high-value or non-standard POs. Route approvals to specific users, roles, or dynamic approvers based on the requester's cost centre.

2
Configure invoice approval thresholds

Set invoice approval rules that trigger when an invoice exceeds a percentage variance from the PO amount (e.g., >5% variance requires approval). Define automatic matching rules — invoices matching PO and goods receipt within tolerance auto-approve. Unmatched or three-way mismatch invoices route to AP team review.

3
Establish journal entry approval policy

Configure manual journal entry rules — standard journals post directly, adjusting journals above a threshold require manager approval, system-generated journals (depreciation, FX revaluation) are auto-approved. Define mandatory review fields such as supporting attachment and business justification for non-standard entries.

4
Set up workflow escalation rules

Configure escalation timers — if an approval is not actioned within 48 hours, the request escalates to the next level approver. Send reminder notifications at 24 hours and escalation alerts at 48 hours. Approvers can delegate or reassign pending approvals with full audit trail of the delegation chain.

Tip

Set up journal approval workflows with thresholds: journals under R10,000 post automatically; over R100,000 require CFO approval.

Perform Bank Reconciliation

1
Configure matching algorithm parameters

Adjust the fuzzy match sensitivity for automated transaction matching — set tolerance percentages for amount matching, date range windows (3 days before/after), and reference field pattern rules. Configure exact match rules for electronic payments where the bank reference matches the system payment ID.

2
Upload statement and review matches

Import bank statements in CSV, MT940, or OFX format. The system presents suggested matches grouped by confidence level (high/medium/low). Review and confirm matches in batch, or manually match unmatched items using the side-by-side statement vs ledger view.

3
Generate uncleared item aging

Run the uncleared items aging report to identify transactions that remain unmatched beyond the reconciliation period. Aged items are categorized into buckets (1-30 days, 31-60, 61-90, 90+). Investigate stale items — cheques that haven't been cashed, deposits not yet credited — and initiate follow-up or write-off as appropriate.

4
Post reconciliation and archive

Once all items are matched or resolved, post the reconciliation. The system updates the GL bank account to reflect the reconciled balance and generates a reconciliation report. Archive the reconciliation report with the bank statement for audit purposes. The system prevents reconciliation for already-locked periods.

5
Perform multi-account reconciliation

For companies with multiple bank accounts, run reconciliations in parallel or sequence. Use the consolidated reconciliation dashboard to monitor the reconciliation status of all accounts at a glance. Set up reconciliation review workflows where a senior accountant reviews and approves each completed reconciliation.

Generate Financial Reports

1
Generate P&L by cost centre

Run the profit and loss statement with cost centre or dimension breakdown. Configure column layouts — actual, budget, prior period, variance % — per reporting group. Use the drill-down feature to navigate from the P&L summary to the underlying account balances and individual transactions.

2
Run balance sheet with comparatives

Generate the balance sheet with period-end balances, prior period comparatives, and period-over-period change columns. Configure subtotal sections for current assets, non-current assets, current liabilities, and equity. The system validates that total assets equal total liabilities plus equity.

3
Generate cash flow statement

Select between the direct method (cash receipts and payments disclosed) or indirect method (starting from net profit with non-cash adjustments). The system maps GL account categories to cash flow sections automatically. Validate the statement by ensuring net change in cash equals the difference between opening and closing bank balances.

4
Run budget vs actual with variance analysis

Compare actual financial results against budgeted amounts with percentage and absolute variance calculations. Configure variance thresholds — variances exceeding 10% or R50,000 are flagged for management commentary. Use the variance analysis report to identify areas requiring corrective action and update forecasts accordingly.

5
Use the custom report designer and schedule distribution

Design custom financial reports using the drag-and-drop report designer — select account groups, column layouts, filters, and formatting. Save report templates and schedule automated distribution via email in PDF or Excel format. Reports can be sent to distribution lists with role-based access control.

Handle Audit Preparation

1
Perform GL drill-down from report to transaction

Starting from any financial report, click through from the summary balance to the underlying GL account activity, then to the individual journal entries, and finally to the source document (invoice, PO, goods receipt). This drill-down path provides auditors with complete transactional transparency without requiring database access.

2
Attach supporting documents

Every journal entry supports document attachments — scanned invoices, signed approvals, contracts, board resolutions. Configure mandatory attachment rules for specific journal types (e.g., adjusting entries require supporting documentation). Documents are stored in the system's document management repository and included in audit export packages.

3
Export the audit trail

Generate the audit trail report for a selected date range, user, account, or transaction type. The report includes field-level before/after values, timestamps, user IDs, and IP addresses. Export in CSV or PDF format for external auditors. The audit trail is tamper-evident — any alteration to historical audit records is flagged.

4
Verify period locks

Run the period-lock verification report to confirm that all periods are closed and locked according to the company's close schedule. Any unauthorized unlocking or post-closing adjustments are highlighted with the user, timestamp, and reason. Provide this report to auditors as evidence of period integrity controls.

Info

The audit trail captures field-level before/after values with timestamps and user IDs — export for external auditors in CSV or PDF format.

Create Recurring Journal Templates

1
Define template types

Create recurring journal templates by type — accrual (auto-reversing next period), amortization (spread over multiple periods), and allocation (distribute to multiple dimensions). Each template defines the source account, target accounts, and the calculation method for the journal amount.

2
Configure variable amount calculation rules

Set up rules that calculate the journal amount dynamically — a fixed amount, a percentage of another account's balance, a formula based on activity metrics (e.g., sales volume x rate), or a spreadsheet-like calculation with multiple variables. Use lookup functions to pull allocation basis data from other modules.

3
Set schedule frequency

Define the posting frequency — monthly, quarterly, annually, or custom intervals. For monthly templates, specify the day of month for automatic generation (e.g., last day of month, first business day). Set start and end dates for the template's validity period. Templates can be paused or skipped for individual periods.

4
Configure auto-posting vs review-required

Set each template to auto-post (journal is created and posted without user intervention) or review-required (journal is created but held in draft for review and approval). Auto-posting templates include system-generated accruals and amortizations; review-required templates cover estimates and management adjustments.

5
Manage template versioning

Templates support version history — when a template is modified, the previous version is archived with effective dates. Use the template change log to track who modified what and when. If a template change affects future postings, the system recalculates pending journals using the new version.

Related Modules

Stock & Inventory

Inventory valuation adjustments (FIFO layer updates, standard cost variances) post directly to GL accounts configured in the Stock module's accounting rules.

Production & Manufacturing

Work order variances — material usage, labour rate, and overhead absorption — post to variance GL accounts for manufacturing cost analysis.

CRM & Sales

Revenue recognition rules can be configured per sales order with deferred revenue schedules and milestone-based recognition.

Compliance & Governance

VAT control accounts in the GL are automatically reconciled against VAT return totals during period-end close.
